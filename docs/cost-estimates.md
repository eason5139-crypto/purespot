# PURESPOT 商品成本估算依據

更新：2026-11-09。現有 80 款商品的單件成本已填入資料庫，來源均標為 `ESTIMATE`。這是進貨規劃用的初始值，**不是供應商報價、實際付款金額或已核實的商品毛利**。

## 計算方式

單件估算成本＝商品目前售價 × 分類成本比率，四捨五入至新臺幣整數，最低 1 元。分類比率如下：

| 分類 | 比率 | 分類 | 比率 |
| --- | ---: | --- | ---: |
| 主食乾糧 | 36% | 主食罐頭 | 45% |
| 鮮食餐包 | 48% | 凍乾主食 | 50% |
| 風乾主食 | 46% | 機能配方 | 42% |
| 小動物主食 | 38% | 零食點心 | 43% |
| 玩具互動 | 40% | 居家用品 | 45% |
| 清潔照護 | 42% | 外出用品 | 47% |
| 飲水餐具 | 44% | 舒壓嗅聞 | 43% |
| 戶外安全 | 47% | 日常保養 | 44% |

其他分類暫採 43%。比率是保守規劃假設，並非從單一賣場價格直接換算。公開供應價格隨重量、材質、起訂量、客製包裝和運送方式變動；網站現有商品也尚無逐款供應商資訊，因此不能把公開報價套成確定的採購價。

參考的公開價格訊號：[OEM 乾糧供應頁](https://www.alibaba.com/product-detail/Wholesale-Direct-Sale-Private-Label-High_1601023199909.html)、[凍乾食品供應頁](https://www.alibaba.com/product-introduction/Wholesale-Bulk-Freeze-Dried-Dog-Treats_1601288478391.html)、[台灣寵物用品與玩具價格](https://www.kaojing-pet.com/products/index.php?group_id=7211)。這些商品和 PURESPOT 商品不是同款，報價不能視為實際進貨成本。

## 管理方式與報表口徑

- 在「商品管理 → 編輯詳情 → 商務」輸入供應商確認的每件成本，來源會改為 `MANUAL`；留空會依分類及售價重新估算。
- 批次進貨記錄確認當下的單件成本，之後修改商品成本不會追改已記錄的進貨金額。新訂單也會保存下單當下的成本快照。
- 月進貨成本只加總入庫；耗損與負向庫存校正另外加總，並以「庫存成本負擔」呈現兩者合計。耗損是已購庫存的損失，並不等於再次付款。[IAS 2](https://www.ifrs.org/issued-standards/list-of-standards/ias-2-inventories/) 將存貨損失認列為費用，故分列較不會誤讀現金支出。
- ABC 報表的商品毛利＝商品營收－銷出件數 × 單件成本；未包含運費、廣告、付款手續費、稅及其他營運費用。舊訂單沒有成本快照時，使用目前成本回推，報表會標示含估算。
- 功能啟用前的存貨沒有進貨流水，不會倒填本月採購金額。
